## Checks run

- The actual Agent CLI verified 36 of 36 release deployments using `preflight --inventory`. Medium `preflight` verified 32 of 32 required combinations, prepared 41 of 41 linked XDP ELF targets, and checked four HAL Firmware ELFs. The 41 include separate Metrics and Trace network builds, 21 EXB2 deployments, and two case slots.
- The Agent reused each released AOT case XDP ELF at A. Its B envelopes changed the name and target to `0x40381000`. Both 432-byte payload digests matched the independent evidence. The `case_mark_idle` output XDP ELF SHA-256 is `fceda735f28060de658c80e773be92a3d4e243a2cd99344dd45832e2ca54d0bc`. `case_swap_idle` was checked with a temporary profile. `case_mark_idle_jit` still rejects a B layout mismatch as a diagnostic.
- Agent, serial, and perf package tests passed 23, 82, and 30 tests respectively. The serial test suite ignored one test. RV32IMC case Trace, native and rBPF network Trace, and four HAL builds linked.
- The Linux runner passed 40 unit tests for the 29-cell plan and rejection of `hot_swap`. The bare `medium-plan` entry was checked using an embedded temporary configuration. The checkout was restored to `run = ["medium"]`.
- A disposable PostgreSQL 18.4 instance used the existing `protocol_v1.sql`. The case writer fixture and `medium_run.sql` query read one switch, eight Trace event rows, and both original artifacts from qualification run `5da084f0-78f2-4c51-9576-a736fa79f869`. This fixture uses synthetic evidence and measures no device.

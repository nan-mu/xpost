TX frames contain 82 B. Their IPv4 length is 68 B. Their UDP length is 48 B.
The anomalous RX frames contain 122 to 642 B. The captured and original lengths match.
IPv4 and UDP lengths account for the full payload in each RX.
The first difference occurs after the first 40 payload bytes.
Every extra 40-byte block matches a separate TX by UUID, sequence, and bytes.
The longest RX UDP payload contains 600 B. The HAL input buffer holds 256 B.
The return path produced aggregated capture records. The aggregation point remains unconfirmed.
The PCAP does not provide independent arrival timestamps for the embedded replies.
Keep these windows inconclusive for the full loss and RTT analysis.
The valid 400 pps window serves as the same-rate control.
The old campaign has no equivalent valid 1400 pps control.
